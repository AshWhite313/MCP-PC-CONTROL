# Knowledge Brain do MCP-PC-CONTROL

Memória do projeto no formato do brain-template (skills `/brain`), para navegar no Obsidian.

- `raw/`: fontes imutáveis. `raw/sources/agent-logs/` guarda o registro da sessão de desenvolvimento.
- `brain/`: páginas de conhecimento com `[[wikilinks]]`. Comece por `brain/_index.md`.

Para continuar alimentando, instale as skills do brain-template e rode `/brain-ingest <fonte>` a partir desta
pasta (`knowledge/`). Para navegar, abra a pasta `brain/` como vault no Obsidian.
